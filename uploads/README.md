# 📥 Deine Upload-Box

Hier kannst du jederzeit Dateien hochladen — auch in Pausen, damit nichts verloren geht.

## So lädst du hoch (30 Sekunden)
1. Diesen Ordner auf GitHub öffnen
2. **Add file → Upload files**
3. Dateien reinziehen → **Commit changes**

## Ordner
- `bilder/` — Fotos, Logo, Produktcover, Screenshots
- `texte/` — Blog-Texte, Ideen, Notizen (Word, PDF, Markdown … alles okay)
- `sonstiges/` — alles andere

## Und dann?
Sag Claude in irgendeiner Sitzung einfach:
> „Schau in die Upload-Box im wowmoman-Repo und bau die neuen Dateien ein."

Claude holt sich die Dateien und arbeitet sie in die Website ein.
